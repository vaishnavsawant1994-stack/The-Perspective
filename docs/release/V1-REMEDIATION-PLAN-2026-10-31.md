## Immediate implementation tranche

With the security fix live and the documentation PR updated, start with P0 auth/tenant qualification in a disposable database and the P0 critical-route journey suite. These expose security and customer-impacting defects without changing production. In parallel, an authorized project owner/admin can gather backup, GitHub ruleset, and alerting capability evidence. Do not begin V1.1 routes, migrations, profile automation, or a V1.0 certification decision until the relevant gates pass.
