# V1 release notes

STATUS: **NOT A RELEASE**

R1 through R13 are the accepted product: authentication, tenancy, authorization, CRM, communications, commercial work, editorial production, publishing, media distribution, growth, the client desk, the member library, and organization settings with integration declarations.

R14 adds qualification tooling only: liveness and readiness routes, a small set of response headers, a production-configuration fail-closed switch, a qualification backup/restore script, and a technical workflow. It does not add a product capability.

Payments, email, and external integrations are not operational. Opening a desk does not grant authority. This document is not a certification and not a production announcement.
